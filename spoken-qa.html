Struct vs class

Q: Difference?

Struct = value type (copied). Class = reference type (heap reference).

Q: What prints?

struct S { public int X; }
var a = new S { X = 1 };
var b = a; b.X = 2;
Console.WriteLine(a.X); // 1 — copy
// class → prints 2 (same object)

Q: When pick a struct?

Small, immutable, “is a value” (Point, money). Default to class for domain objects, identity, inheritance, mutable/large.

Q: Can a struct inherit a class?

No. Can implement interfaces only.

String / StringBuilder

Q: Are strings mutable?

No. Every change allocates a new string.

Q: Why not s += x in a loop?

Each += recopies → O(n²). Use StringBuilder.Append, then ToString().

Q: String vs StringBuilder?

string for normal text. StringBuilder when building in a loop / many pieces.

IEnumerable · List · IList

Q: Ladder?

  • IEnumerable<T> — foreach only (LINQ; often lazy)
  • ICollection<T> — Count, Add/Remove
  • IList<T> / List<T> — index [i]

Q: What should a coding problem return?

List<T> / IList<T> — concrete, indexable, safe.

Q: Deferred execution?

var q = xs.Where(...); does nothing yet. Runs on foreach / ToList / Count / First.

Q: Trap — why include the 4?

var numbers = new List<int> { 1, 2, 3 };
var q = numbers.Select(x => x * 2);
numbers.Add(4);
// foreach q → 2,4,6,8 (live data)
// Fix: .ToList() for a snapshot

Q: IEnumerable vs IQueryable?

In-memory Func vs expression tree → SQL. Today’s round is in-memory.

Event infinite loops (Glassdoor)

Q: How do you prevent them?

Handler writes state → same event fires again → loop.

  • No-op guard — same value → don’t publish
  • Command ≠ event — don’t re-issue blindly
  • Idempotent handlers
  • Version / correlation — ignore self/stale

Example: TextChanged → save → save raises TextChanged. Fix: only save on real change, or suppress while applying.

async / await — yield; continue after Task without blocking the thread
static — belongs to the type; no instance required
Transient vs Singleton — new each resolve vs one for app lifetime (Scoped = per request)
